3. Technical requirements

Built with

  • HTML5 - semantic markup, one file per page
  • CSS3 - a single shared stylesheet at css/style.css, using CSS Grid and Flexbox for layout
  • Vanilla JavaScript - js/script.js, no frameworks (the only library is Leaflet, used for the contact-page map)

Folder structure

  • home.html, about.html, products.html, contact.html, enquiry.html, planning.html
  • css/style.css - all styling
  • js/script.js - mobile menu, product list, lightbox, accordion, form validation, AJAX, map
  • images/ - logo, product photos, promotional image, QR code (compressed, descriptive file names)
  • robots.txt, sitemap.xml - search engine files
  • README.md, CHANGELOG.md - documentation

Browser & device support

  • Latest versions of Chrome, Edge, Firefox and Safari
  • Responsive down to a 360px-wide mobile screen (images and tables scale with max-width: 100%)

Known limitations

  • The enquiry form sends its data to a free test API (JSONPlaceholder), so enquiries are validated and answered on screen but not stored or emailed. The contact form builds an email that the visitor sends from their own email app.
  • No payment processing is included - orders are handled manually via the enquiry form and Instagram.
